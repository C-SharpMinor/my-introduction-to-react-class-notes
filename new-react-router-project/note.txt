Introduction to React Router**
Routing means deciding which page to display based on the URL.

For example:
-------------------------------------------------------
| URL path             | Page displayed               |
|----------------------|------------------------------|
| `/`                  | Home                         |
| `/about`             | About                        |
| `/courses`           | Courses                      |
| `/courses/html`      | Details about HTML           |
| `/dashboard/profile` | Profile inside the dashboard |
-------------------------------------------------------
Without routing, you might render several components together:

function App() {
  return (
    <>
      <Home />
      <About />
      <Courses />
    </>
  );
}

This displays all three components on the same page.npm run dev


With routing, we describe which component should appear at each URL.
React Router connects URL paths to React components. Its declarative approach uses components such as `BrowserRouter`, `Routes`, and `Route`. You already know how to create components. Routing lets us choose which component to show when someone visits a particular address.

Learning goals
By the end, you should be able to:
1. Set up browser routing.
2. Connect paths to page components.
3. Navigate using `Link`.
4. Create routes containing changing values.
5. Read route parameters.
6. Display child pages inside a shared layout.
7. Navigate or redirect users to another page.

==========WHAT DOES BROWSER ROUTER DO?=============
What does BrowserRouter do?
`BrowserRouter` connects React Router to the browser’s address bar and history. This allows routing to work with normal paths and the browser’s Back and Forward buttons.

========HOW TO ENABLE ROUTING ==========

============ NAVIGATION USING LINK =============
4. Navigation using `Link`
Typing URLs manually works, but users need clickable navigation.
Use `Link` for navigation between routes in the application.

<Link to="/about">About</Link>

- `Link` creates a navigational link.
- `to` specifies the destination.
- `About` is the visible text.

----------
For ordinary internal clicks, `Link` changes the route without requesting a whole new HTML document. Use a normal `<a>` element for external destinations.

<Link to="/about">About our portal</Link>

E.g.
<a href="https://www.wikipedia.org">
  Visit Wikipedia
</a>

============DYNAMIC ROUTES============
5. Dynamic routes
A dynamic route contains a part that can change.

Compare:
<Route path="/about" element={<About />} />

with:

<Route path="/courses/:courseId" element={<CourseDetails />} />

`/about` is fixed.

In `/courses/:courseId`, the value after `/courses/` can vary.
------------------------------------------
| URL              | Value of `courseId` |
|------------------|---------------------|
| `/courses/html`  | `"html"`            |
| `/courses/css`   | `"css"`             |
| `/courses/react` | `"react"`           |
------------------------------------------
The colon introduces a dynamic segment in the route definition. A real URL uses a value such as `html`.

==========ROUTE PARAMETERS WITH 'useParams'
6. Route parameters with `useParams`
A route parameter is a value captured from a dynamic part of the URL.

- Dynamic route: Defines where a changing value belongs.
-Route parameter: The actual value captured there.
Use `useParams()` to read that value.

import { Link, useParams } from "react-router";

const CourseDetails = () => {
  const { courseId } = useParams();

  const courses = [
    { id: "html", title: "HTML Fundamentals", duration: "2 weeks" },
    { id: "css", title: "CSS Styling", duration: "3 weeks" },
    { id: "react", title: "React Development", duration: "4 weeks" },
  ];

  const selectedCourse = courses.find(
    (course) => course.id === courseId
  );

  if (!selectedCourse) {
    return (
      <section>
        <h1>Course not found</h1>
        <Link to="/courses">Back to courses</Link>
      </section>
    );
  }

  return (
    <section>
      <h1>{selectedCourse.title}</h1>
      <p>Duration: {selectedCourse.duration}</p>
      <Link to="/courses">Back to courses</Link>
    </section>
  );
};

export default CourseDetails;

--------------
========Explanation of the process========
1. `useParams()` reads the course ID.
2. `.find()` looks for a course with that ID.
3. If a course exists, its details appear.
4. Otherwise, the component displays **Course not found.


========ROUTE PARAMETER VALUES=========
Route parameter values are strings when present. If your data uses numeric IDs, convert or compare appropriately:
course.id === Number(courseId)

=========NESTED ROUTES=========
7. Nested routes
Nested routes allow a child page to appear inside a parent layout.
For example, a dashboard can contain:

- A heading that remains visible.
- Dashboard navigation that remains visible.
- A changing area for Profile or Settings.
-------------------------------------------------------------
| URL                   | Parent layout | Content inside it |
|-----------------------|---------------|-------------------|
| `/dashboard`          | Dashboard     | Overview          |
| `/dashboard/profile`  | Dashboard     | Profile           |
| `/dashboard/settings` | Dashboard     | Settings          |
-------------------------------------------------------------

The parent component uses `Outlet` to mark where the matched child component appears. An index route supplies the default child at the parent URL.

======REDIRECTING USERS=====
8. Redirecting users
A redirect sends someone from one location to another automatically.

Examples include:
- Sending an old page address to its replacement.
- Sending a user to a confirmation page after completing an action.

For this lesson, we will use:
------------------------------------------------------------------
| Tool            | Use                                          |
|-----------------|----------------------------------------------|
| `<Navigate />`  | Navigate when a component is rendered        |
| `useNavigate()` | Navigate from code, such as an event handler |
------------------------------------------------------------------

useNavigate() is a React Router hook that lets you move to another page using JavaScript, usually after an action such as submitting a form.

In this use case, use <Link> for navigation links; use navigate() when navigation follows an action in your code.

   Guided task 10 — Redirect an old URL
Suppose `/all-courses` was the old address for `/courses`.
1. Open `App.tsx`.
2. Add `Navigate` to the router import:
import { Routes, Route, Navigate } from "react-router";
3. Add this route inside `Routes`:
<Route
  path="/all-courses"
  element={<Navigate to="/courses" replace />}
/>

4. Visit `/all-courses`.
Expected outcome: The URL changes to `/courses`, and the Courses page appears.

`replace` replaces the current browser history entry, so the old URL does not remain as an extra Back-button step.
