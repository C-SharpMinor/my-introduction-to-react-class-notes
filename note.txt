Introduction to React

What is React?

React is a JavaScript library  developed by Microsoft for building user interfaces.

A user interface is the part of an application that users see and interact with, such as navigation menus, buttons, forms, and cards.

React allows us to divide a page into smaller parts called components. For example, a course website could contain:
- A header.
- A navigation bar.
- Course cards.
- A registration form.
- A footer.

Why React was built
As applications become more interactive, keeping their displayed content consistent with their data can become difficult.
React provides a way to organise interfaces into components and update the displayed content when data changes.


====================Introduction to TypeScript======================
TypeScript extends JavaScript by adding a system for checking types before the code runs. TypeScript is a programming language built on JavaScript. It adds a type system that helps detect mistakes before your code runs.
const name = "Bukola';
const name: string = "Bukola";

const age = 12;
const age: number = 12;

const isDamiPresent = false;
const isDamiPresent: boolean = false;

The annotations describe the values each variable should contain:
Type	| Meaning	    |   Example
string	| Text	        |  "Bukola"
number	| A number	    |  12
boolean | true or false |	false

For example:
let score: number = 85;

score = 90;       // Valid
score = "ninety"; // TypeScript reports an error

Browsers run JavaScript. The development tools convert TypeScript into JavaScript.

EXTENSIONS/INSTALLATIONS:
1. Node.js with npm
npm is a package manager commonly used with Node.js and JavaScript projects. It helps you install and manage packages—reusable code and tools written by other developers.

In your React project, you use npm to:
- Install the project’s dependencies:
  npm install
- Add a package, such as Tailwind CSS:
  npm install tailwindcss @tailwindcss/vite
- Run a command defined in package.json:
  npm run dev
  
  In your Vite project, this starts the development server so you can view the application in your browser.
For students: “npm helps us download the packages our application needs and run our project’s development commands.”

npm normally comes with Node.js. Check that it is installed by running:
npm -v

============Benefits of using TypeScript with React==============

TypeScript helps us check the data passed into components and identify mistakes while writing code. Editors can also provide useful suggestions based on those types.

---------Differences between JSX and TSX---------
-------FIRST, HOW TO CREATE .TS, .JSX AND .TSX files
A file extension** is the part after the dot in a filename. It tells your development tools what kind of code to expect.

COMPARE THE THREE
| Extension | What to write inside it | Example                           |
|-----------|-------------------------|-----------------------------------|
| `.ts`     | TypeScript without JSX  | `const age: number = 22;`         |
| `.jsx`    | JavaScript with JSX    | `return <h1>Hello</h1>;`          |
| `.tsx`    | TypeScript with JSX     | A typed variable displayed inside `<h1>`|
NOTE: .jsx: JavaScript with JSX is unique for its use of HTML markup style.
These files are created in the same way. It is the extension at the end of the filename determines the file type.
